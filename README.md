# Qarmet Corporate Taxi MVP

## Дополнения: автопарк, карта и отчёты

- Демонстрационный автопарк содержит 15 автомобилей и 15 водителей. Начальная миграция дополняет существующий `backend/data.json`, сохраняя заказы и историю.
- Диспетчеру доступны страницы автопарка, водителей, карты и отчётов. Назначение автомобиля остаётся ручным; рекомендации показывают только подходящие машины с водителем на смене и достаточной вместимостью.
- GPS-позиции поступают из браузера водителя. Координаты старше 20 минут не участвуют в расчёте прямого расстояния. Это оценка по прямой, не дорожный маршрут и не ETA.
- Заказ можно оформить через подсказки адреса или карту; FastAPI проксирует поиск и обратное геокодирование через авторизованные маршруты.
- Отчёты доступны диспетчеру в формате Excel и ZIP с нормализованными CSV для Power BI: «Поездки», «Водители», «Автомобили», «Сотрудники», «Остановки», «История событий». Заголовки и статусы выгрузки на русском; даты показаны в часовом поясе `Asia/Almaty` как `ДД.ММ.ГГГГ ЧЧ`. Отсутствующие расстояния и длительности остаются пустыми.

### Настройка картографических сервисов

Карта использует OSM-тайлы с видимой атрибуцией. URL тайлов можно заменить в `frontend/.env`:

```env
VITE_API_URL=http://localhost:8000/api
VITE_MAP_TILE_URL=https://tile.openstreetmap.org/{z}/{x}/{y}.png
```

Для поиска адресов backend обращается к Nominatim. Можно задать совместимый адрес сервиса через `QARMET_NOMINATIM_URL` перед запуском API. Поиск ограничен одним запросом в секунду на процесс, результаты кэшируются в памяти.

Публичные OSM-сервисы предоставляются по правилам их операторов. Для нагруженного или производственного развёртывания настройте собственного поставщика тайлов и геокодирования.

Демо система корпоративных поездок: FastAPI API и React интерфейсы диспетчера, водителя и сотрудника. Данные хранятся в JSON файле; приложение автоматически добавляет начальные данные при первом запуске и не сбрасывает файл при перезапуске.

## Требования

- Python 3.10+
- Node.js 20+

## Запуск в Windows PowerShell

В первом окне из корня проекта:

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m uvicorn app.main:app --reload --port 8000
```

API: http://localhost:8000, Swagger: http://localhost:8000/docs. По умолчанию файл данных: `backend/data.json`. Чтобы выбрать другой файл, задайте `$env:QARMET_DATA` до запуска сервера.

Для backend тестов (из папки `backend`): `python -m unittest discover -s tests -v`.

Во втором окне:

```powershell
cd frontend
npm install
npm run dev
```

Откройте http://localhost:5173. Для проверки совместной работы откройте несколько окон браузера и выберите разные роли. Данные обновляются опросом API каждые 2,5 секунды. Сессии выдаются API и сохраняются в браузере.

## Возможности MVP

- Демо вход по роли с проверкой bearer сессии и прав на сервере.
- Создание, поиск, просмотр жизненного цикла, отмена поездок; ручное назначение единственной машины диспетчером.
- Очередь при занятой машине, обязательная активная смена для назначения и действий водителя.
- Управление сменой, GPS обновление только браузерной геопозицией, SOS и сообщения о поломке.
- События аудита и уведомлений, статистика из сохраненных данных.
- Валидация маршрута, вместимости, расписания и переходов статуса.

## Архитектура и ограничения

Интерфейс опрашивает API каждые 2,5 секунды. Карта показывает реальные GPS-позиции от браузера водителя и маркеры реального маршрута; демо-координаты не генерируются.

Демо-вход не является производственной аутентификацией. Реальные корпоративные учётные данные и SSO не подключены. В демо-данных 15 водителей и 15 автомобилей. Данные хранятся в backend/data.json.
